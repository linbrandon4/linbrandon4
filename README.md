# Brandon Lin

Georgia Tech computer science student and cofounder of [Totem](https://totemlayer.com).

I build AI systems and full-stack software. At Totem, I work on identity and action-level authorization for AI agents operating across company boundaries. My other work includes AI model evaluation and post-training, soft robotics research, and software engineering.

## Selected work

- [Totem](https://totemlayer.com): cross-company AI-agent identity and authorization.
- [quantlab](https://github.com/linbrandon4/quantlab-fastapi-backtesting-service): a FastAPI service for vectorized strategy backtests and risk metrics.
- [Verdant](https://github.com/linbrandon4/Verdant): a computer-vision workflow that turns drone imagery into infrastructure damage reports and repair recommendations.
- [Is It Recyclable?](https://github.com/linbrandon4/Is-It-Recyclable-): a team-built CNN for material and recyclability classification that won first place at HackGwinnett.
- [VEX Robotics 675B](https://github.com/linbrandon4/Vex-Robotics-675B-OverUnder): competition robot software for the VEX Over Under season.

## Current interests

AI evaluation and post-training, agent security, robotics, applied machine learning, and reliable software systems.
